How to read this report

Fields describe captured observations, not required schema fields or proven incompatibility. Repeated requests pair by encounter order; reordered responses and request-body variants may be ambiguous. Origins and query values participate in matching; query values are omitted from labels. Different operations can therefore have identical labels. Entry numbers refer to the original HAR log.entries, starting at 1.

Headers, cookies, body values, URL credentials, query values and fragments are excluded. Origin/path and JSON field names can still be sensitive: review this artifact before sharing. No traffic is replayed and no model or external asset is loaded.
