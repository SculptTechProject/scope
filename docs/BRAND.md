# Scope identity

Scope's public documentation uses the same visual language as the desktop:
navy `#17212c`, action blue `#2f64ed`, signal mint `#55d8c6`, plain surfaces and
readable typography. The magnifier/pulse mark comes from `resources/scope.svg`.

The README banner is an original static SVG. Its request → rule → record
sequence explains a real workflow; it is an illustration, not an app screenshot.
Screenshots are separately recorded in `docs/images/README.md`.

Use concrete verbs and evidence: capture, rewrite, replay, save, inspect. Keep
scope, privacy and synthetic provenance visible. Avoid unsupported claims such
as universal pinning bypass, complete API inference, independent security audit
or enterprise certification. A proposed version is not a published release.

Prefer repository-owned assets and a small number of useful status badges.
Keep primary information in Markdown so it remains accessible if images are
unavailable, and retain upstream notices alongside the project's identity.
