# Scope 1.2.2: GLib backport maintenance review

The Linux GTK/WebKit dependency family still requires GLib 0.18.5. This proposal
incorporates PR #27's narrow backport of the upstream `VariantStrIter` soundness
fix, preserving the compatible family and the real upstream version rather than
changing the version to satisfy a scanner.

The pristine crates.io archive, its original license and all 121 files are
retained. Only the upstream two-line fix changes vendored source. Offline
full-tree verification, locked Cargo selection and optimized Linux iterator
regressions run in normal checks and release validation. Verification also pins
Git byte conversion and UTF-8 metadata decoding for Windows. Generated notices
retain gtk-rs authorship and identify the original crate, modified source and
backport provenance.

Application/npm/Cargo/Tauri versions agree on **1.2.2**. The test-only GLib
regression package retains version `0.0.0`; unrelated dependency versions do not
change. Capture/replay behavior, archive formats, the HAR CLI/Action and public
native-runtime exclusions are unchanged.

## Review evidence and boundaries

- The pristine optimized iterator comparison produced seven independent
  `SIGSEGV` results; the nine patched iterator cases pass. Fifteen additional
  Linux characterization cases exercise the concrete conversions and ownership
  assumptions in CodeQL's reports. Their execution is separate from interactive
  GTK/dialog or installer acceptance.
- Initial CodeQL alerts 4–10 were individually reviewed against exact SARIF
  `2114338864`. Alert 11, introduced by the new test-only boxed derive, was
  separately reviewed against SARIF `2114713790` at `eec083e`; the charset/error
  paths conflate generic conversions with `CountedBoxed` pointer conversion.
  [The separate review record](https://github.com/dalkedev/scope/pull/27#issuecomment-6693586655)
  accompanies its individual false-positive disposition. No blanket suppression,
  vendor exclusion or disabled scanner is included. Any new alert needs its own
  review.
- Cargo-audit excludes local path packages from registry advisory matching.
  GLib's absent registry warning therefore does not validate this backport;
  source integrity and real optimized tests provide that evidence. Other
  version-based scanners may still report GLib 0.18.5.
- [Dependency findings](../DEPENDENCIES.md), [backport provenance](../../vendor/glib-provenance/README.md)
  and [recorded verification](../VERIFICATION.md) retain their exact host and
  version boundaries. Issue #11 remains open for interactive GTK/dialog testing.

## Validation and publication gates

The final candidate must include the reviewed macOS notice-path portability fix
from the same feature branch, then regenerate notices from the final locks.
Run the exact candidate's three desktop checks, HAR workflows, integrity and
attribution suites, CodeQL and release-resource checks before merge. Earlier
feature-head results do not replace checks of this proposal's final commit.

Use one canonical bot-authored release proposal, incorporating PR #27 without
losing its commits. Retain strict platform checks, maintainer/codeowner review
and all protection settings; close the incorporated feature PR with a link to
this proposal rather than leaving overlapping review requests open.

After normal approval and merge, tag the reviewed main commit as `v1.2.2` and
build that exact tag into a draft. Verify downloaded assets, manifest commits,
source-archive completeness and checksums before publishing with the
[1.2.2 release notes](1.2.2.md). Preserve historical tags and assets.

This candidate does not claim new interactive desktop/device validation. macOS
is ad-hoc signed without Apple notarization; Windows/Linux interactive behavior
remains experimental and Intel macOS is unverified. Optional native Frida
binaries remain excluded from public packages.
