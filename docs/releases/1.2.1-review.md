# Scope 1.2.1: supported macOS builds

The macOS 14 arm64 runner now fails before any job steps run. This maintenance
proposal incorporates the reviewed macOS 15 runner change into CI and release
packaging, without changing application deployment-target settings.

Application/npm/Cargo/Tauri versions agree on **1.2.1**. External dependencies,
capture/replay behavior, archive formats and the HAR comparison CLI/Action are
unchanged. Generated notices retain their license texts and reflect the updated
lock hashes and local Scope package versions.

Current-status documentation distinguishes the already published 1.2.0 release
from this maintenance candidate. Historical verification records and release
notes keep their original version boundaries.

## Validation and publication gates

The exact proposal commit must pass the three desktop checks, HAR workflows and
release-resource checks before merge. The required macOS status context must
match the new runner label, while retaining Windows/Linux checks, maintainer
review and all existing protection settings.

Use the normal maintainer approval and merge path. Tag the reviewed main commit
as `v1.2.1`, build it into a draft, verify the manifests and checksums, and inspect
the assets before publishing. Do not modify historical release tags or assets.

This proposal does not claim new interactive desktop/device validation. macOS is
ad-hoc signed without Apple notarization; Windows/Linux interactive behavior
remains experimental and Intel macOS is unverified. Optional native Frida
binaries remain excluded from public packages.
