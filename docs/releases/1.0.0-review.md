## Scope 1.0.0 proposal

Captured traffic can now drive persistent rewrite, mock and block rules. Replay
has a request composer, sessions have notes/tags/pins and deletion safeguards,
and Android setup has a read-only diagnostic report. MCP adds observed OpenAPI
inference, edited replay and separately authorized global rules/diagnostics.

Rules preserve original messages and record applied-rule evidence. In-flight
requests have an explicit state. Rule configuration is snapshotted per request;
manual breakpoints run after rules. Sanitized archive export is a separate,
clearly lossy sharing option; ordinary local archives retain the captured data.

The version bump is a review proposal. This PR does not publish 1.0.0. Native
branch protection requires SculptTechProject's approving review and successful
macOS/Windows/Linux checks before merge. New commits dismiss stale approval.

## Validation

Current results and platform boundaries are maintained in
[docs/VERIFICATION.md](../VERIFICATION.md). CI builds the three desktop targets;
runtime/device verification remains narrower than build support. The macOS app
is ad-hoc signed, not notarized. Optional Frida native components are installed
separately; the Linux glib advisory remains tracked in #11.

## Review focus

- Session deletion guards, archive compatibility and SQLite migration.
- Default-deny MCP permissions, redaction and global-rule scope.
- Device preflight remains read-only; Stop/recovery behavior and compatibility limits.
- [Public issue research](../USER-NEEDS.md), docs and genuine native screenshots.

No automatic approval, merge, version tag or public release is performed here.
